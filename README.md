# Labo 3 · Simuladores de dinámica (Física I)

Sitio estático: portada + 2 simulaciones con canvas + ES modules. Cero dependencias.

🌐 Web: https://bilboheadbangins.github.io/labo3/

- `index.html` — portada
- `sim-polea.html` — mesa + polea (`physics.js`)
- `sim-plano.html` — plano inclinado (`incline.js`)

## Uso en el celular

Abrí la URL en Chrome/Safari → `⋮ → Agregar a pantalla principal`.

## Desarrollo local

```bash
python3 -m http.server
# http://localhost:8000/
npm test
```
